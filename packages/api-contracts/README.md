# packages/api-contracts

The formal API contract is the **OpenAPI document generated by FastAPI**:

```
http://localhost:8000/api/v1/openapi.json
```

It is generated from the Pydantic schemas, so it cannot drift from the
implementation — which is why it is not hand-maintained here.

This package exists as the home for generated clients when a second consumer
appears (the React Native app, or a partner integration):

```bash
# Example, once a mobile client exists:
npx openapi-typescript http://localhost:8000/api/v1/openapi.json -o ./src/schema.d.ts
```

Until then, the web client's `src/types/index.ts` is the hand-written mirror,
kept small and reviewed against the OpenAPI document.
